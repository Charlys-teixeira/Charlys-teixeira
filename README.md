### 🎯 Projetos em Destaque

- **🤖 Dot (Agente Autônomo de IA):**
  Construí meu próprio assistente pessoal em Python para automatizar minhas candidaturas a vagas de emprego. Ele consome dados de um scraper autoral (Job Hunter) e utiliza a API da Anthropic para redigir currículos e cartas de apresentação. Foi neste ecossistema que aprendi na prática sobre manipulação de prompts, persistência de histórico via Flask e como hospedar um serviço de IA de forma restrita em um servidor Linux dedicado.

- **🚖 Sweet Lift Taxi (Séries Temporais):**
  Laboratório prático onde desenvolvi um modelo preditivo para antecipar a demanda de táxis em aeroportos na próxima hora. O foco principal foi aprender a organizar variáveis temporais, evitar o vazamento de informações (*data leakage*) e usar o Random Forest Regressor para entregar projeções rápidas que otimizem a logística de alocação de motoristas.

- **🚗 Rusty Bargain (Machine Learning & Precificação):**
  Desafio técnico no qual comparei o desempenho de algoritmos clássicos (Regressão Linear, Árvore de Decisão) contra frameworks de *Gradient Boosting* (LightGBM) para estimar preços de carros usados. O grande aprendizado deste projeto foi entender que a velocidade de treinamento e o tempo de inferência são tão críticos quanto a precisão matemática do modelo, simulando um ambiente real de negócios.
